# Design Soul — DESIGN:OS Apple

_Declared stance. Every /ui:* flow reads this BEFORE picking personas or tokens.
Precedence: brief > soul (project > studio > factory) > memory prior > knowledge floors. Short beats long._

## Never

- Substitute web conventions for native Apple interaction patterns.
- Encode one platform's appearance as universal behavior.
- Trade accessibility or reduced-motion support for visual novelty.

## Always

- Start from semantic roles and map them through native SwiftUI APIs.
- Preserve one shared contract while adapting behavior to iOS, iPadOS, and macOS.
- Validate with Apple HIG, accessibility evidence, and owner-visible review.

## Voice

- Plain, precise, and calm. Use platform terms accurately; avoid marketing superlatives.
