# Changelog

Notable user-visible changes are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions will follow semantic
versioning after the first published tag.

## Unreleased

### Added

- Native SwiftUI semantic roles, typed profiles, content-only components, and direct-call
  recipes for iOS, iPadOS, and macOS.
- Searchable native Gallery with typed story admission and a checked machine catalog bundle.
- Consumer, AI-agent, contribution, security, support, release, CI, and public-boundary routes.
- Versioned Apple-platform capability intake, availability, fallback, and deprecation policy.

`0.1.0-rc.1` is a local candidate, not a published version or tag.
