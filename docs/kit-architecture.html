Native SwiftUI kit architecture

Apple Design OS composes a screen from small source-backed layers. The implementation is merged into main; the catalog pins reviewed source 1898ce2. No tagged release is claimed.

How the layers compose

Primitives
Geometry, clipping and adaptive arrangement. Internal helpers remain distinct from public APIs.
Semantic components
Meaningful media, identity, labeled values, surfaces and native action styling.
Composites
Reusable groups with caller-owned content slots and native controls.
Shells
Container, scrolling, safe-area and navigation policies.
Screen types
Eighteen task-oriented compositions assembled from the same layers.

What the app still owns

The consuming app owns state, navigation routes, services, data, actions and the actual native controls. The kit does not implement backend services or a full reference app.

Styles, configuration and tokens

AppStyle, Profile and semantic token roles remain the theme authorities. Public configuration includes compact or regular secondary actions, filled or outlined treatment, intrinsic or expanded selection summaries, and neutral or emphasized outgoing message content.

Evidence and limits

The catalog publishes 142 native iPhone images from source 1898ce2. Source helpers without standalone previews are labeled. Capture and test evidence does not establish every state or full accessibility acceptance.
