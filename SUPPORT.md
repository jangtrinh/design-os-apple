# Support

Use a GitHub issue for a reproducible package, Gallery, documentation, or platform-adaptation
problem. Include the Apple platform and OS, Xcode and Swift versions, package revision,
smallest reproduction, expected behavior, and actual behavior.

Use a discussion route, when enabled, for API-design questions and usage guidance. Use the
[Security Policy](SECURITY.md) for sensitive vulnerabilities and the
[Code of Conduct](CODE_OF_CONDUCT.md) for conduct concerns.

Apple Design OS is community-maintained and has no service-level agreement. Questions about
Apple frameworks or HIG policy should be verified against current Apple documentation; this
project cannot provide Apple support or endorsement.
